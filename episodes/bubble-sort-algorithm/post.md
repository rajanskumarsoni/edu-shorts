How Bubble Sort Algorithm Works | Computer Science Explainer

DESCRIPTION:
Learn how the Bubble Sort algorithm works through the intuitive school assembly lineup analogy. Watch adjacent pairs compare, swap, and bubble the largest element to the end in O(n^2) worst case and O(n) best case.

FACTS TO VERIFY BEFORE PUBLISHING:
- Standard Bubble Sort worst and average time complexity is O(n^2)
- Optimized Bubble Sort best time complexity with swapped flag is O(n)
- Space complexity is O(1) in-place auxiliary memory
- Total comparisons in full unoptimized pass is n * (n - 1) / 2
